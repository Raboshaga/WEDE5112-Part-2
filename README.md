# Lakaze Kota Bar & Catering - WEDE Part 2

## Website pages

This website contains exactly six HTML pages:

1. `index.html` - Home
2. `about.html` - About
3. `services.html` - Services, menu, catering and event food services
4. `gallery.html` - Gallery
5. `enquiry.html` - Enquiry form
6. `contact.html` - Contact information and message form

## Part 2 features included

- One external stylesheet used by all six pages
- CSS reset and consistent base styling
- Responsive typography with `clamp()` and relative units
- CSS Grid and Flexbox layouts
- Hover, focus and active pseudo-classes
- Desktop, tablet and mobile media queries
- Responsive navigation with a mobile menu
- Responsive multi-column layouts
- Responsive forms
- Responsive images using `picture`, `srcset` and `sizes`
- Accessible alt text, form labels and active navigation
- External JavaScript file
